Simple White Noise
==================

Generates stereo white noise with a single Volume parameter. Instrument plug-in in VST® 3 and CLAP formats.
ステレオのホワイトノイズを発生させる音源のプラグインです。パラメーターは音量 (Volume) だけです。VST® 3 と CLAP の形式で配布します。

Source code and verification / ソースコードと検証:
  https://github.com/AllegroMoltoV/simple-whitenoise-audio

Lower the volume of your monitors before you insert the plug-in. White noise at 0 dB is loud.
プラグインを挿す前に、モニターの音量を下げてください。0 dB のホワイトノイズは大きな音です。

Install / 導入
--------------

1. Close your DAW. / DAW を終了します。
2. Copy the folder "simple-whitenoise.vst3" to the VST 3 folder:
   「simple-whitenoise.vst3」フォルダーを、VST 3 のフォルダーへコピーします。
     Windows: C:\Program Files\Common Files\VST3\   (needs administrator / 管理者権限が必要)
     Linux:   ~/.vst3/
3. For CLAP hosts, copy "simple-whitenoise.clap" to the CLAP folder:
   CLAP に対応した DAW では、「simple-whitenoise.clap」を CLAP のフォルダーへコピーします。
     Windows: C:\Program Files\Common Files\CLAP\
     Linux:   ~/.clap/
4. Start your DAW and rescan plug-ins if needed. / DAW を起動し、必要ならプラグインを再スキャンします。

No installer and no network access. The plug-in does not read or write files.
インストーラーはありません。プラグインは通信しません。ファイルを読み書きしません。
